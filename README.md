# NBA_Streaming

  NBA_Streaming is a benchmark for fine-grained basketball commentary generation from continuous video streams.

  Paper (https://arxiv.org/abs/2608.09200)

  ## Annotations

  This repository provides event annotations and dataset splits. Each annotation contains an English commentary (caption), a start time (start_time), and an end time (end_time). Timestamps are measured in seconds
  from the beginning of the corresponding period video.
